Drive RAID

Drive RAID is a personal, self-hosted backup tool. It runs on the owner's own server and keeps a backup copy of that server's folders in the owner's own Google Drive accounts, splitting each file across several accounts with parity, like a RAID 5 array.

It uses the Google Drive API through rclone to create and read files inside a folder named DriveRAID in the accounts the owner connects. It only reads and writes that person's own files, on that person's own machine. There is no hosted service, no account to sign up for and no fee.
